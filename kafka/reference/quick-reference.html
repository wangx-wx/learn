本地环境与 CLI 速查

单节点 Docker 环境 + 最常用的命令行工具。排障时第一个翻的地方。

打印友好 适用 Kafka 3.9 / KRaft 模式
环境约定

所有 kafka-*.sh 命令都在容器内执行，路径固定为 /opt/kafka/bin/。用 docker exec 而不是从宿主机连 —— 这样可以完全绕开 advertised.listeners 的配置坑。

环境生命周期

启动单节点 broker

KRaft 模式，无需 ZooKeeper。启动约需 15 秒。

docker run -d --name kafka -p 9092:9092 apache/kafka:3.9.0

确认启动成功

docker logs kafka | tail -5

进入容器（反复执行 CLI 时更省事）

docker exec -it kafka bash

停止并删除容器

数据一并丢失 —— 学习环境无所谓，生产环境千万别这么干。

docker rm -f kafka

Topic 管理

建 topic

docker exec kafka /opt/kafka/bin/kafka-topics.sh \
  --bootstrap-server localhost:9092 \
  --create --topic <名称> --partitions 3 --replication-factor 1

列出所有 topic

docker exec kafka /opt/kafka/bin/kafka-topics.sh \
  --bootstrap-server localhost:9092 --list

查看 topic 详情（分区、副本分布）

docker exec kafka /opt/kafka/bin/kafka-topics.sh \
  --bootstrap-server localhost:9092 --describe --topic <名称>

增加分区

只能增不能减。注意：增加分区会打乱已有 key 的分区映射，破坏按 key 的顺序。

docker exec kafka /opt/kafka/bin/kafka-topics.sh \
  --bootstrap-server localhost:9092 \
  --alter --topic <名称> --partitions 6

删除 topic

docker exec kafka /opt/kafka/bin/kafka-topics.sh \
  --bootstrap-server localhost:9092 --delete --topic <名称>

生产与消费

写入消息（每行一条）

printf 'a\nb\nc\n' | docker exec -i kafka \
  /opt/kafka/bin/kafka-console-producer.sh \
  --bootstrap-server localhost:9092 --topic <名称>

带 key 写入

key 决定分区，进而决定顺序边界。这是最常用的保序手段。

printf 'k1:v1\nk2:v2\n' | docker exec -i kafka \
  /opt/kafka/bin/kafka-console-producer.sh \
  --bootstrap-server localhost:9092 --topic <名称> \
  --property parse.key=true --property key.separator=:

从头消费（并打印 offset 与分区）

docker exec kafka /opt/kafka/bin/kafka-console-consumer.sh \
  --bootstrap-server localhost:9092 --topic <名称> \
  --from-beginning \
  --property print.offset=true --property print.partition=true

指定消费者组消费

docker exec kafka /opt/kafka/bin/kafka-console-consumer.sh \
  --bootstrap-server localhost:9092 --topic <名称> \
  --group <组名>

查看消费进度

查看消费者组的位点与积压

排障第一命令。LAG 列就是积压量 —— 它等于「日志末端位点 − 已提交位点」。

docker exec kafka /opt/kafka/bin/kafka-consumer-groups.sh \
  --bootstrap-server localhost:9092 --describe --group <组名>

列出所有消费者组

docker exec kafka /opt/kafka/bin/kafka-consumer-groups.sh \
  --bootstrap-server localhost:9092 --list

重置位点（重放的手段）

必须先停掉该组的所有消费者，否则报错。--to-earliest 表示回到最早，--to-datetime 可指定时间点。

docker exec kafka /opt/kafka/bin/kafka-consumer-groups.sh \
  --bootstrap-server localhost:9092 --group <组名> \
  --topic <名称> --reset-offsets --to-earliest --execute

分区与磁盘

查看分区日志的实际大小与位点范围

docker exec kafka /opt/kafka/bin/kafka-log-dirs.sh \
  --bootstrap-server localhost:9092 --topic-list <名称> --describe

查看分区的最早 / 最新位点

两者的差就是当前日志里保留的消息总数。

docker exec kafka /opt/kafka/bin/kafka-get-offsets.sh \
  --bootstrap-server localhost:9092 --topic <名称>
